# v0.2.1 polish batch: design

2026-10-23. A small change; agreed in conversation, written down here.

## Intent

Three small fixes from `docs/parking-lot.md`, shipped as 0.2.1.

## 1. Plugin versioning: unchanged (decided against, 2026-10-23)

Considered and dropped in this batch. The plugin keeps `version`, tied to the crate version by
`plugin_version_matches_crate`; 0.2.1 bumps both.

**Approaches considered.**
- **Drop `version`**, so GitHub installs key on the commit SHA and a skill fix ships on push.
  First picked, then reversed after the red team
  (`../reviews/2026-10-23-v0.2.1-polish-design-redteam.md`): no user but the developer gains
  from it today (their local-path install loads in place and ignores the version; the repo has 0
  stars and 0 forks; `SKILL.md` is unchanged since v0.2.0 apart from its move to `plugin/`), and
  the parked MCP server would tie plugin and binary together again.
- **Independent plugin semver** with a test hashing the skill files. Rejected: more machinery,
  bump still manual.
- **Keep them coupled (picked).** Revisit when a real skill-only fix exists; the parking-lot
  entry carries the findings.

## 2. Full-screen timer: check `-s` before the screen opens

`run_timer` (`src/main.rs`) builds `App` and enters the alternate screen without checking the
sound file, so a bad `-s` fails only at fire time, invisibly. Call `sound::check` before
`tui.init()`, as `remind` (`src/remind.rs:65`) and `ding` (`src/ding.rs:28`) do. A bad file prints
the error and exits 1; the timer never starts.

## 3. Human "set" line shows the day when it isn't today

`src/output.rs` prints `Reminder set at 14:32:05` for any `fires_at`. Keep that when `fires_at` is
today (local time); otherwise print `Reminder set at Sat 24 Oct 14:32:05` (with the label form
likewise). JSON is unchanged. The function is given "now" as a parameter so tests can check both
cases without the clock.

## 4. Licence fields

Add `license = "GPL-3.0-or-later"` to `Cargo.toml` and `"license": "GPL-3.0-or-later"` to
`plugin.json`. `LICENSE` is the stock GPL-3.0 text with no variant stated; the developer picked
"or later" (the GPL's own "How to Apply" wording; the developer is the only copyright holder, so
it can change for later releases).

## Release

Bump `Cargo.toml` and `plugin/.claude-plugin/plugin.json` to 0.2.1, manual release run (dry run),
check the four archives, push `v0.2.1`.

## Non-goals

Other parking-lot entries. No change to JSON output, exit codes, or the skill's wording beyond
what the tests above need.
